JavaLens Pro - 11-Class Pure Java OOP Backend + Built-in Web Studio
====================================================================
100% Standard JDK (Java 11 / 17 / 21) - Zero external JARs!

1. WEB STUDIO MODE (Recommended for Viva & Demo - Java HttpServer):
   javac *.java
   java JavaLensMain --web
   Then open http://localhost:8080 in Chrome!

2. DESKTOP DARK SWING MINI-IDE MODE (100% Pure Java):
   javac *.java
   java JavaLensMain

3. TERMINAL STUDIO MODE (CLI / Termux):
   javac *.java
   java JavaLensMain --cli
